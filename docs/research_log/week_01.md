# Week 1 Research Log

## Objective

Turn a broad interest in AI understanding and consciousness into a precise,
testable, and feasible research project.

## Work completed

- Selected a tiny-transformer fictional-world experiment as the core project.
- Formulated one primary research question and four supporting questions.
- Defined a limited world model operationally.
- Separated behavioral success, internal representation, causal use, and
  consciousness into different levels of evidence.
- Limited the first environment to four agents, four objects, four celestial
  locations, and deterministic travel, automatic-pickup, and drop events.
- Drafted valid state rules and example stories.
- Identified essential work, advanced extensions, and excluded topics.
- Created the initial public-repository structure.

## Important decisions

1. The core task will initially ask who is currently carrying an object.
2. Travel, automatic pickup on arrival, and drop events are sufficient for the
   first simulator.
3. Generalization tests are essential because ordinary accuracy cannot
   distinguish reusable rules from familiar patterns.
4. Linear probes require controls because probe accuracy alone can be
   misleading.
5. Activation patching is a strong extension, not a requirement for completing
   the project.
6. Consciousness will be addressed through philosophical interpretation rather
   than presented as something the experiment detects.
7. Quantum mechanics is outside the scope of this project.

## Development of the question

The original interest concerned whether AI has intelligence, true
understanding, or consciousness. That question was too broad for a controlled
experiment. The project now asks what evidence could distinguish prediction
from a limited internal world model. This narrower question preserves the
philosophical motivation while making the mathematical and computational work
testable.

## Open questions

- What exact mathematical state representation should the simulator use?
- How should reasoning-step length be calculated for each story?
- Which combinations should be withheld to create a valid generalization test?
- What probe controls are feasible within the project timeline?
- What result would count as a successful causal intervention?
